# Smart Parking Management System — Frontend

A complete responsive frontend for a college minor project.

## Included
- Modern landing page
- Login & Register pages
- User dashboard
- Find Parking / live slot grid
- Parking booking page
- Payment page
- Booking history
- User profile
- Admin dashboard
- Shared responsive navigation
- Bootstrap 5 + Bootstrap Icons
- Custom CSS
- Reusable JavaScript interactions
- Demo data and UI-only flows (no backend required)

## How to run
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. For the best experience, use VS Code + Live Server.

## Backend integration points
Replace the demo JavaScript/data with your Flask/PHP/Node/Spring Boot APIs later.

Suggested API areas:
- `/api/login`
- `/api/register`
- `/api/parking/slots`
- `/api/bookings`
- `/api/payment`
- `/api/history`
- `/api/profile`
